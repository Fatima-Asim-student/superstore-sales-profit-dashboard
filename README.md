 Superstore Sales & Profit Dashboard

An interactive Power BI dashboard built to analyze sales and profitability using the Superstore dataset.

🛠️ Tools Used

* Microsoft Power BI
* DAX
* Power Query
* Data Visualization

 📊 Dashboard Analysis

* Sales and profit performance
* Orders and quantity
* Average order value
* Profit margin
* Product and category performance
* Regional and customer segment analysis

 🔎 Key Features

* Interactive Year, Region, Category, and Segment slicers
* KPI cards for key business metrics
* Visual analysis of sales and profit trends
* Interactive filtering for exploring business performance

 📁 Files

* Power BI dashboard (`.pbix`)
* Dashboard screenshot

 🎯 Purpose

This project was created to practice data cleaning, analysis, DAX measures, and interactive dashboard development using Power BI.
